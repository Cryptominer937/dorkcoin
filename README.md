# Dork Core

Dork Core is full-node and wallet software for the Dorkcoin peer-to-peer digital
currency. It connects to and validates the Dorkcoin network, and provides tools
to hold, send, receive, and stake DORK.

The project is maintained in the
[dork-core/dorkcoin repository](https://github.com/dork-core/dorkcoin). Learn
more about [Dorkcoin](https://dorkcoin.org) and the
[Dork Core project](https://dorkcore.org).

See the [changelog](CHANGELOG.md) for release history and the `doc/` directory
for project documentation.
