# Dork Core Security Policy

Dork Core is the node and wallet software for the Dorkcoin network.
Its canonical repository is https://github.com/dork-core/dorkcoin.

## Supported releases

Consult the repository's releases and release notes for maintained versions.
A version number or release build flag is not a guarantee of security.

## Reporting a vulnerability

Do not disclose exploitable vulnerabilities, private keys, wallet files, or
credentials in public issues or pull requests.

Use GitHub private vulnerability reporting at
https://github.com/dork-core/dorkcoin/security/advisories/new if it is enabled.
If that channel is unavailable, request a confidential reporting channel from
the Dork Core maintainers without publishing technical exploit details.
No project security email address or signing key is asserted by this policy.

For bugs independently affecting Bitcoin Core, also follow the upstream
Bitcoin Core security policy. Bitcoin and Blackcoin maintainers are not the
security contact for Dork Core.
