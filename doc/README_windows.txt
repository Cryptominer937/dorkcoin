Dork Core
=========

Dork Core is the node and wallet software for the Dorkcoin network and currency.
Project source, documentation, and releases:
https://github.com/dork-core/dorkcoin

Setup
-----
Unpack the release files and run dorkcoin-qt.exe for the GUI, or dorkcoind.exe
for a headless node. Command-line RPC access is provided by dorkcoin-cli.exe.

The node downloads and verifies the Dorkcoin blockchain. Existing network
parameters, address formats, dorkcoin.conf, and Dorkcoin data-directory names
are preserved. Synchronization time depends on hardware, connectivity, and
chain size.

Back up wallets before upgrading. Consult README.md and the release notes for
validated platforms, wallet migration instructions, and outstanding limitations.
Do not migrate the only copy of a wallet.

Report ordinary bugs to https://github.com/dork-core/dorkcoin/issues.
For vulnerabilities, follow SECURITY.md rather than posting exploit details.
